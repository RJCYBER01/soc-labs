SC-300 — Microsoft Entra ID Identity Lab

Building practical identity administration skills through hands-on Microsoft Entra ID exercises, enterprise scenarios, documented configurations, and verification testing.

Project overview

This lab supports my preparation for Microsoft SC-300: Identity and Access Administrator. It uses an ABC Enterprise training environment to explore cloud identity, identity lifecycle operations, and identity security controls.

Project 01 — User Lifecycle Management

Status: Completed. Implemented a Joiner–Mover–Leaver identity administration scenario using bulk CSV import, Microsoft Graph PowerShell, account disable operations, and sign-in verification.

The exercise demonstrates practical identity provisioning and deprovisioning workflows, including verification of administrative changes. The source project includes masked evidence and implementation documentation.

Implementation approach

1. Joiner: Prepare fictional user records and perform bulk identity provisioning.

2. Mover: Document changes to user identity information during an organizational transition.

3. Leaver: Disable the relevant account and verify the resulting sign-in behavior.

4. Evidence: Document configuration steps, validation results, and troubleshooting with sensitive identifiers masked.
